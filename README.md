# Breast & Chest Wall Constraint Reference

Read-only reference of published breast and chest-wall dose-constraint templates (34 sources, 617 constraints), grouped by regimen and site, with source documents and copy-to-Loop buttons.

Used by the MedStar Washington Hospital Center Radiation Oncology QI project on standardizing breast/chest-wall constraints. Values were compiled from the Radformation ClearCheck template library and the cited protocols and guidelines.

**Reference only.** Verify every value against the primary protocol before clinical use. Proposals, discussion and decisions happen in the project's Loop workspace, not here.

To update: replace `index.html` with the new version (keep the filename).
